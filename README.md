# مَعلَم للتطوير العقاري (موقع تجريبي)

موقع عربي لشركة تطوير عقاري: واجهة بصورة حقيقية، ومشاريع قابلة للبحث، ولماذا نحن، والإحصائيات، وآراء العملاء، ونموذج تواصل يرسل الطلب عبر واتساب.

- الموقع المنشور موجود في فولدر `docs/` ويُعرض عبر GitHub Pages.
- `index.html` في الجذر هو نسخة المصدر.
- أسماء المشاريع والأسعار والأرقام وآراء العملاء أمثلة توضيحية، والصور ليست لمشاريع الشركة.
